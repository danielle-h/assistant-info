Privacy Policy – Personal Assistant

Last updated: 15 October 2026

Personal Assistant ("the app") is a private application used by a single person, its owner. It is not available to the public. This policy explains how the app handles data, including data obtained through Google APIs.

Google user data the app accesses

  • Google Calendar: the app reads events from calendars that have been shared with the app's own Google account, and creates, changes or deletes events only on a calendar it is allowed to write to. It requests no other Google data.

How the data is used

  • Calendar data is used only to show the owner their schedule, find free time, and add or change events at the owner's request.
  • To understand requests, relevant text (for example event titles and times) is processed by an AI model through the Google Gemini API under its paid-tier terms, which do not use the data to train models.
  • The app does not sell, share, transfer or disclose Google user data to anyone, does not use it for advertising, and does not allow humans to read it except the owner.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

  • Calendar events remain in Google Calendar. The app keeps its own task list, reminders and a short conversation history in a database on the owner's computer, with backups in the owner's private cloud storage.
  • Google sign-in tokens are stored only on the owner's computer. Access can be revoked at any time at myaccount.google.com/permissions.
  • The owner can delete any stored data at any time.
